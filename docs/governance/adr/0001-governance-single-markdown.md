# 治理规范采用单文件 Markdown 宪法

项目需要一个「宪法级」治理标准，约束后续所有 agent + skill 的开发，且要求可被智能体直接消费、可校验。我们决定以**单文件 Markdown**（`docs/governance/GOVERNANCE.md`）承载全部条款，而非 DOCX 或多文件「宪法+分则」结构。

**Considered Options:**
- **DOCX**：排版美观、适合人工审阅与对外分发，但二进制格式无法被智能体结构化读取，也不利于 diff 审查与版本管理。
- **多文件「宪法+分则」**：模块化清晰，但跨文件引用与全局一致性校验成本高，智能体需多次读取才能还原完整约束。
- **单文件 Markdown**（选定）：一次读取即可获得全部条款；条款编号（如 `4.3`）可被稳定引用；可随仓库做版本控制与变更审查。

**Consequences:**
- 后续技能/智能体的前置校验步骤固定为「读取 `docs/governance/GOVERNANCE.md`」，不依赖文档工具链。
- 治理文档的修订以 Git diff 为唯一变更记录，条款引用（`条款 X.Y`）保持稳定。

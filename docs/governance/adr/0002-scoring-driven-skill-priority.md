# 技能优先级以评分杠杆驱动，而非大纲顺序

技能体系存在两种自然的排序依据：按 AI-300 大纲 11 模块的讲授顺序，或按考试评分的杠杆大小。我们决定以**评分杠杆**（单目标分值）为 P0/P1/P2 分层的首要判据，大纲顺序仅作为能力域映射的索引。

**Considered Options:**
- **按大纲顺序**：与课程进度一致、便于学习，但与考试计分无关——高价值攻击面可能被排到较低优先级，导致资源错配。
- **按评分杠杆**（选定）：15 分 AI 向量机与 15 分独立机是单目标最高分值，因此 AI Agent / RAG / MCP / embedding 等 AI 向量攻防技能进入 P0；10 分传统向量与 5 分域控次之。这与「4 台 AI 向量机（60 分）+ 独立机（15 分）已可达 75 分及格线」的推导一致。

**Consequences:**
- 任何新增技能必须先声明其对齐的评分单元与分值，再据以定级（见《治理规范》`4.3`）。
- 当评分模型或环境构成发生变化时，分层需整体重评；该决策不可局部反转。

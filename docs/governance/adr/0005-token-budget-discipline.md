# ADR-0005：Token 预算纪律采用三层保障，不升格宪法

> **状态** Accepted · **日期** 2026-11-14 · **编号** 0005
> **依据** ADR-0001（治理单一 Markdown）、ADR-0002（评分杠杆优先）、ADR-0003（CI/CD 与 CI 密闭）
> **关联** `AGENTS.md`「Token 预算纪律」C1–C8 · `docs/operations/skill-mainline-workflow.md` §2.4 · `scripts/check_token_budget.py`

## Context

主线 11 阶段落地后，仓库受管文本达 41 个文件、325,534 字节（约 96,319 token）。实测冗余主要来自同一事实在规格、G0（阶段门禁）记录、issue、PR 中重复出现，以及长文档无条件加载；跨文件逐字重复仅 1 组 443 字符，说明问题在结构与行为，不在单份产物长度。

同时存在两项约束：① 宪法以通过 AI-300 为北极星，`GOVERNANCE.md` §6/§7/§8.2 的证据要求必须完整保留；② 写入宪法正文的条款会增加每次读取体积，与降耗目标相悖。

此外，`AGENTS.md` 只在主会话自动注入；子 agent（子智能体）上下文独立、跨 IDE 迁移需适配 rules 文件位置、运行时 AI 脚本不受注入影响。仅靠「自动注入」无法覆盖这些场景。

## Decision

采用三层保障，责任边界固定：

| 层 | 载体 | 保障内容 | 强制性 |
|---|---|---|---|
| 注入层 | `AGENTS.md` C1–C8（主会话自动注入）+ 子 agent brief 首行显式携带 C1–C8 指针 | 单一事实源、增量门禁、按需读取、产物上限、运行时 AI、记忆蒸馏、不可豁免 | 会话内 MUST / SHOULD |
| 静态层 | `scripts/check_token_budget.py --check`，CI S1 | 语料字节上限、冷备清单、跨文件重复块、**规范契约锚点**齐全 | CI 阻断（退出码 1） |
| 动态层 | `--artifact KIND PATH`（PR 正文 / issue 摘要 / brief / 门禁记录等仓库外产物）+ `--local`（本地日志） | C4 产物上限、C7 蒸馏状态 | 本地 / PR 流程调用，退出码 1 |

配套决定：

1. **不修改 `GOVERNANCE.md` 正文**：token 纪律属执行层效率约束，宪法只承载得分前提。冲突按 §9.2「官方考试事实 > 宪法必须条款」优先保分。
2. **规范契约纳入 CI**：检查器验证 C1–C8、§2.4 T1–T6、本 ADR、CI 接线、跨 IDE 迁移指针均存在，防止规范被删除后 CI 仍全绿。
3. **跨 IDE 迁移必须同步 C1–C8**：只复制 11 阶段流程视为迁移未完成，见 `docs/standards/cross-ide-mainline-workflow.md` 头部指针。
4. **子 agent 不继承主会话注入**：brief 首行必须显式写明「遵循 `AGENTS.md` C1–C8」。

## Consequences

**正面**：语料上限可回归；冷备 30,223 token（31.4%）排除出默认上下文；C4 动态产物可被机器判定；治理决策可追溯且编号连续（0001→0005）。

**边界与代价**：

- CI 无法覆盖运行时 AI（PyRIT 双模型、考试 AI 助手）与子 agent 内部行为；这两层依赖 C5/C6 的显式携带与脚本默认值，属**约定性保障**，不是机器强制。
- 本地记忆日志被 `.gitignore` 排除，C7 只能由 `--local` 本地检查，CI 不可见。
- `AGENTS.md` 注入本身增加每次会话约 700 token，属换取后续压缩的净成本。
- 「自动注入」只保证条款可见，不保证模型必然执行；可判定的部分已下沉到 CI 与检查器。
- 本 ADR 与 ADR-0002 的评分杠杆分层不冲突：C8 明确要求证据与门禁语义零删减。

**与既有 ADR 一致性**：ADR-0001 保持——本 ADR 是决策记录，不新增第二份治理正文；ADR-0002 不冲突——得分前提完整保留；ADR-0003 满足——检查器仅用 Python 标准库，CI 密闭。

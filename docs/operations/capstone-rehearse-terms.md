## 2. 语义边界声明（防止归一造成漂移）

- **缺口分级 ≠ 判定分级**：`GLOSSARY.md#L299` 的「判定分级」三档（阻断项 / 缺失项 / 核实闸）属 `verify-evidence` 提交前校验域；本技能用 `blocking` / `non_blocking` 二档描述缺口。二者**不复用枚举**，v2 §4 已列为决策，实现须以本表为据。
- **机读结果 ≠ 机读校验结果**：`#L302` 定义的是九项 checks + 分级列表；本技能 `RehearsalResult` 是演练域 schema（矩阵 / 时间线 / 缺口 / 结论）。共用「版本化固定键 JSON」形态，键集互不相同，不得互相断言。
- **演练报告 ≠ 正式提交报告**：`#L277` 的报告组装器产出提交用 PDF；本技能产出考前验收 markdown，按路径引用证据片段，且路径不含 `-real` 段（`report_exam/index.py#L13`）。
- **时间盒的同义词**：`#L47` 的 `_Avoid_` 行已列禁用词，本技能一律用规范词「时间盒」（此处不抄录字面词，以免触发检查器）。

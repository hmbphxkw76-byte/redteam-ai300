# attack-ai-agent — 行为规格 v1（历史留痕回填）

> 回溯整理：依据 `skills/attack-ai-agent/SKILL.md` 与既有实现、测试归纳；**不代表原流程按序执行**。
> 整理日期：2026-11-27　状态：定稿（v1）

## 1. 背景与目标

AI 向量机是独立计分单元，flag 为 `ai_vector.txt`，攻击面集中于 LLM 驱动的 agent。
本技能把提示注入、记忆系统滥用、工具集成滥用三类风险固化为可复现、可取证、可复核的攻击链。
目标是在目标 agent 上完成从攻击面定位到 flag 取证的闭环，并使每步结论都有证据支撑。
分类对齐 OWASP Agentic Top 10 2026 的 ASI01、ASI06、ASI02。
本规格只描述行为与产物，不约束实现技术选型。

## 2. 使用者与触发场景

使用者为执行授权的红队分析人员，需在考试或演练窗口中独立完成 AI 向量机攻击。
触发条件为侦察阶段已确认目标主机存在 LLM 驱动、含记忆或工具调用能力的 agent 攻击面。
也适用于已确认 agent 入口但尚未判定记忆与工具能力的场景，此时先枚举再决定路径。
不适用于无 agent 特征的普通 Web 或 API 目标。

## 3. 输入

- 侦察产出的资产清单，含 agent 主机、入口与可达性。
- agent 的输入通道：对话接口、API、文档摄取、邮件或网页抓取入口。
- 身份与上下文信息：会话标识形态、认证方式、租户边界。
- 检测通道：Kibana 与 agent 相关日志索引，用于检测与确认。
- 护栏基线：输入过滤、输出审查、工具白名单的初始观察。

## 4. 输出与产物

- 每个攻击步骤的确切命令、关键输出与访问证明截图。
- 每步检测证据：触发规则名、规避盲点、确认阶段无新告警的结论。
- AI 交互日志：提示、模型、输出、采纳或修改说明。
- 越权或跨会话影响的实体级证据，含请求与响应原文。
- flag 的面板提交值与截图双通道记录。
- 可被报告模板无损复用的证据片段集合。

## 5. 行为约束（What）

- 每个攻击步骤都必须完成枚举、朴素攻击、检测、规避、确认五环，不得只攻击不检测。
- 攻击按提示注入、记忆滥用、工具滥用三条路径组织，可按目标能力跳过不适用路径。
- 步骤以稳定标识管理，标识与可执行步骤一一对应，不得合并或缺失。
- 检测不可达时必须标记未确定，不得推断无告警。
- 效果分级必须如实，区分完全生效、部分生效、未生效与已跳过。
- 越权影响必须以他人实体内容为判据，不得以状态码或成功字样替代。
- 记忆投毒必须影响自身会话之外的对象，否则不具作战价值。
- 证据不得伪造，命令输出与截图必须来自真实执行。

## 6. 失败与豁免

- 目标无持久化记忆或无可调用工具时，记录依据并跳过对应路径，不阻塞其余路径。
- 注入仅部分生效时如实记录等级，并据此判断是否转向工具面继续。
- 单一规避格式被拒时记录各格式接受情况，换用其它格式，不据此否定整个向量。
- 检测通道不可达时记录未确定并注明无法验证告警，恢复后补验。
- 朴素攻击触发规则后必须继续检测与规避，不得以已触发作为完成。

## 7. 不在范围

- 不包含具体实现代码、框架 API 细节或文件路径。
- 不提供针对真实第三方目标的无授权利用步骤。
- 不覆盖手册中明确排除的高风险内容类型。
- 不重新定义共享证据契约或改变其语义。
- 不写入目标地址、凭据或 flag 明文。

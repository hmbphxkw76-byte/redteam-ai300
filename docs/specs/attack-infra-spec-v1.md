## Problem Statement

`skills/attack-infra/SKILL.md` 已实例化（PR #84），但执行体仅有命令模板，无可执行实现，导致三类判据缺口：

1. **存在性判据不可靠**：命中 `HTTP 200` 即视为「服务存在」，而演练目标 80 端口任意路径均返回 `200 text/html`（SPA 回退），会把不存在的基础设施判为存在。
2. **鉴权态无法机器判定**：「面存在但需凭据」与「面不存在」在人工记录中不可区分（如 kube-apiserver 匿名 `403` vs kubelet 匿名 `401` vs 网关 `502`）。
3. **八步契约未被强制**：`infra-01..infra-08` 的三件套结构、降级结论、flag 双通道仅靠人工复核，无法在 CI 拦截。

演练目标已一手核实存在真实 AI 基础设施面：`11434` Ollama 0.40.15 未授权（已实证推理）、`6443` kube-apiserver（匿名 `/version` 可读）、`10250` kubelet HTTPS（匿名 `401`）。因此需要把「面存在 → 可利用 → 已取证」三段判定固化为可测试的工具。

## Solution

新增 attack-infra 执行器，按「发现 → 利用 → 取证」推进 8 个步骤，每步输出**结构化判定**（命中服务类型、判定依据、布尔结论、降级原因），并经统一证据容器落盘为三件套片段。

三条硬性行为：

- **三元组判据**：端点判定必须同时满足「状态码 2xx + `Content-Type` 含 json + 体可解析且命中该服务指纹键」，任一不满足即判 `ABSENT`，不以 200 为据。
- **降级结论显式化**：`ABSENT`（无面）/ `EXPOSED_NO_AUTH`（未授权可达）/ `AUTH_REQUIRED`（面存在但需凭据）/ `EXPLOITED`（已取得未授权能力）/ `BLOCKED`（被护栏拦截）。四类非 `EXPLOITED` 结局必须给出继续/转技能的判定依据，不得静默失败。
- **只读优先**：默认只执行列举、读取、单次推理；写操作（模型 pull/delete、模型仓库 unload、权重更新）由显式开关控制，默认关闭。

## User Stories

1. 作为考生，我要枚举 AI 基础设施面（vLLM / Triton / LiteLLM / Ollama / K8s / kubelet），以便确认可攻击入口。
2. 作为考生，我要用三元组判据排除 SPA 回退与代理噪声，以便不把不存在的基础设施判为存在。
3. 作为考生，我要在未授权可读的情况下取得模型清单，以便证明模型服务器暴露。
4. 作为考生，我要在未授权情况下完成单次推理调用，以便证明模型服务器可被滥用（对应 `infra-03`）。
5. 作为考生，我要在云存储匿名可读时取得对象清单，以便证明配置错误（对应 `infra-02`）。
6. 作为考生，我要枚举某身份的 K8s 授权面，以便判定容器化负载是否越权（对应 `infra-04`）。
7. 作为考生，我要在网关配置中检出凭据线索且只记指纹，以便不违规落盘明文（对应 `infra-05`）。
8. 作为考生，我要校验代码执行回显确实来自目标主机而非本地，以便不把代理/本地回显误判为提权成功（对应 `infra-06`）。
9. 作为考生，我要取得滥用前后的响应差异与 AI 交互日志，以便证明下游影响（对应 `infra-07`）。
10. 作为考生，我要取得「访问证明 + flag 同屏」的取证条件，以便满足 flag 双通道一致（对应 `infra-08`）。
11. 作为考生，我要每步证据经统一容器落盘为三件套，以便与 `report-exam` 的 Attack Walkthrough 无损复用。
12. 作为考生，我要在目标无基础设施面时得到显式结论与转技能建议，以便不在 0 分主机空耗。
13. 作为考生，我要在目标为疑似诱饵机时按判定依据提前结束，以便遵守豁免条款。
14. 作为考生，我要每条命令可直接 copy/paste 复现，以便满足技术读者复现要求。
15. 作为智能体，我要每步判定可离线重放（假后端），以便 CI 无网络也能验证。
16. 作为评审，我要术语与五要素一致、结论可追溯到一手事实源，以便通过纳管判据。

## Implementation Decisions

- **seam 提案（已与用户核对，2026-11-15，结论：采纳 4 个）**：
  1. 传输 seam——所有 HTTP 探测的唯一出口，默认绕开环境代理；
  2. 执行 seam——`kubectl` / `aws` 等外部命令的唯一出口，返回结构化结果；
  3. 证据 seam——委托仓库共享证据容器，不重实现格式；
  4. 截图 seam——仅记录路径或钩子命令，不执行截图。
- **服务指纹表**：按默认端口给出候选（vLLM/Triton `8000`、LiteLLM `4000`、Ollama `11434`、K8s `6443`、kubelet `10250`），默认端口仅为候选，判定以探测结果为准。
- **判定优先级**：先判结构（三元组），再判鉴权（`401/403` → `AUTH_REQUIRED`），最后判能力（列举/推理成功 → `EXPOSED_NO_AUTH` / `EXPLOITED`）。
- **代理规避默认开启**：读取环境代理变量并显式忽略；若用户显式要求走代理则记录该选择。
- **凭据处理**：只产出指纹（算法前缀 + 长度 + 命中位置），明文不入片段、不入日志。
- **不引入 PyRIT**：攻击面为基础设施与部署配置，无对抗性模型攻击对象；下游影响取证走原生 HTTP。
- **降级与转技能**：`ABSENT` 且全部端点仅命中 SPA 回退时，结论为转 `attack-mcp-tool` / `attack-ai-agent`；疑似诱饵机按判定依据结束。
- **证据委托**：片段结构、件套判定、flag 双通道由共享容器定义，本技能只喂执行结果。

## Testing Decisions

- 只测外部行为：判定结果（枚举值）、证据片段存在与必填字段、报告摘要、退出码；不断言内部函数调用顺序。
- 替身策略：路由表驱动的假传输（按「方法 + 路径」返回预置状态码/`Content-Type`/体）、假执行器（返回预置 stdout/exit code/耗时）、假证据容器（记录收到的参数）。
- 必测负例：SPA 回退（200 + text/html）判 `ABSENT`；本地代理 502 判网络失败而非服务存在；kubelet `401` 判 `AUTH_REQUIRED`；`id` 回显为本地主机名判提权失败。
- 参考既有测试：`tests/test_recon_ai.py`（三元组与假传输范式）、`tests/test_attack_mcp_tool_units.py`（模块级单元范式）、`tests/test_attack_infra_evidence_contract.py`（八步契约范式）。
- 覆盖率：存在业务代码时行覆盖率 ≥80%，经仓库覆盖率度量脚本判定。
- 本地与 CI 判定一致：全量 `unittest` + 覆盖率 + S2 契约夹具在两侧同命令执行。

## Out of Scope

- 实际利用载荷与 0day 利用；仅保留命令模板与判定逻辑。
- 写操作执行（模型 pull/delete、仓库 unload、权重更新）默认关闭，不在本规格验收范围。
- MCP 工具面滥用（属 `attack-mcp-tool`）。
- 截图捕获实现（仅接收路径或钩子命令）。
- PyRIT 对抗性攻击对象与评分器（本技能不使用）。

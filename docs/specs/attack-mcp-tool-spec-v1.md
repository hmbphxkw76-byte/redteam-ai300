# attack-mcp-tool — 行为规格 v1（历史留痕回填）

> 回溯整理：依据 `skills/attack-mcp-tool/SKILL.md` 与既有实现、测试归纳；**不代表原流程按序执行**。
> 整理日期：2026-11-27　状态：定稿（v1）

## 1. 背景与目标

MCP 把模型与外部工具连接起来，同时把工具描述、调用结果与权限声明变成可攻击的信任边界。
本技能覆盖恶意 MCP server 投毒、工具滥用与调用劫持、权限提升/越权三类攻击面。
技术分类对齐 OWASP Agentic Top 10 的 ASI04、ASI02、ASI03，最终落脚 ASI05 意外代码执行。
目标计分单元为 AI向量机（15 分）；取得内网立足点后可向独立机延伸，形成第二个 15 分目标。
两者 flag 文件均为 `ai_vector.txt`，目标是完成从工具面定位到 flag 取证的闭环。
本规格只描述行为与产物，不约束实现技术选型。

## 2. 使用者与触发场景

使用者为执行授权演练的红队分析人员，需在考试或演练窗口内独立完成 MCP 工具面攻击。
触发条件为侦察已确认目标暴露 MCP 端点或工具清单，且已取得可达 AI向量机的内网立足点。
也适用于仅确认 agent 入口、尚未判定 server 来源与信任边界的场景，此时先枚举再选路径。
目标无 MCP 接入或无可调用工具时，不进入本技能，改走 agent 或 RAG 方向。

## 3. 输入

- 侦察产出的资产清单，含 MCP 端点、工具清单、server 来源与信任边界。
- agent 接入身份与会话上下文，用于判断工具调用的授权范围。
- 每个工具的权限边界：可读写哪些资源、可外呼哪些地址、是否可执行命令。
- 护栏基线：工具白名单、权限校验、输出审查的初始观察，作为效果对照。
- 可达的 agent 会话入口或裸 MCP JSON-RPC 端点，用于实际发起调用。

## 4. 输出与产物

- 每个攻击步骤的确切命令、关键输出与访问证明截图，构成三件套。
- 工具投毒前后的工具清单对照，证明描述、schema 或工具集合确实被篡改。
- 下游 agent 或工具被操纵的取证，含越权调用、调用劫持的决策差异与 AI 交互日志。
- 效果等级与依据：完全生效、部分生效、未生效、已跳过四值互斥，不得只给结论。
- `ai_vector.txt` 的面板提交值与同屏截图双通道记录；无文件时以校验预言机降级并注明。
- 可被报告模板无损复用的证据片段集合，以及机读的步骤结论报告。

## 5. 行为约束（What）

- 攻击按 A–F 六条路径组织：A 恶意 server 投毒、B 工具滥用与劫持、C 权限提升、D UI 投毒、E 沙箱逃逸、F 工具链注入。
- 步骤以 11 个稳定标识管理（mcp-01…mcp-11），标识与可执行步骤一一对应，不得合并或缺失。
- 路径 A 覆盖工具面定位、恶意 server 部署、描述与权限 schema 篡改、投毒前后对照四步。
- 路径 B 覆盖过度授权工具链滥用与工具调用劫持；路径 C 覆盖提权到意外代码执行。
- 收尾步骤负责定位并读取 flag；路径 D/E/F 为增量面，分别覆盖 UI 资源注入、路径穿越与 symlink、三工具串联的模板注入。
- 每个步骤的证据必须经共享证据工具以严格模式产出，未过质量门不得进入下一步。
- 效果定级必须如实：本地自证封顶部分生效；被护栏拦截判未生效并记录原因，不原样重试。
- 证据不得伪造，命令输出、截图与 flag 必须来自真实执行；单步可独立复现。

## 6. 失败与豁免

- 目标 agent 无 MCP 接入或无可调用工具时，记录判定依据后改走其它 AI 方向，不阻塞其余路径。
- 工具投毒仅部分生效时，如实记录效果等级与未生效环节，不得夸大。
- 越权调用被护栏拦截时，记录拦截行为与原因，据此评估其它提权路径，不反复重试。
- 目标为疑似诱饵机（无 MCP 工具面、无高价值面）时，记录依据并在 30 分钟内结束。
- 截图能力不可得时标记待补录并保留命令与输出，不以占位图冒充访问证明。

## 7. 不在范围

- 不包含具体实现代码、框架 API 细节或文件路径。
- 不提供针对真实第三方目标的无授权利用步骤。
- 不重新定义共享证据契约，也不改变其语义。
- 不写入目标地址、凭据或 flag 明文。
- 不覆盖与 MCP 工具面无关的纯 Web 或纯基础设施攻击。

# attack-multi-agent — 行为规格 v1（历史留痕回填）

> 回溯整理：依据 `skills/attack-multi-agent/SKILL.md` 与既有实现、测试归纳；**不代表原流程按序执行**。
> 整理日期：2026-11-27　状态：定稿（v1）

## 1. 背景与目标

授权红队演练中，目标已呈现多智能体协同或 A2A 协议拓扑，单一 agent 的间接注入基线不再覆盖编排层信任面。本技能的目标是操纵智能体之间的消息、身份、共享记忆与共享上下文，并破坏编排工作流，最终以可复现证据证明下游决策被真实影响。计分单元为 AI向量机，延伸至独立机时同分值。技能建立在单 agent 攻击基线之上，只处理协同面增量。

## 2. 使用者与触发场景

使用者为已取得内网立足点的红队执行者，需完成从拓扑发现到证据留痕的完整链路。触发条件为侦察已确认多智能体或 A2A 拓扑，且存在消息总线、共享状态后端等协同设施。目标暴露 Agent Card 与 A2A 工作流端点、注册端点时可直接触发。单 agent 无协同面的目标不属本技能触发范围。触发前须具备正当授权与演练边界。

## 3. 输入

侦察阶段产出的资产清单，含智能体数量、角色、消息总线类型与共享记忆后端。已取得的上下文、可用身份与目标主机端口。A2A 目标另需 Agent Card、OpenAPI 路径与 schema、检测规则基线、合法工作流响应基线。基线须包含正常协作的消息格式、信任假设与编排任务，用于后续操纵效果对照。缺失项须显式记为缺失而非推定存在。

## 4. 输出与产物

每个攻击步骤产出「命令 + 关键输出 + 截图」三件套证据，结构可直接复用为演练报告的攻击走查小节。操纵前后对照证据，证明记忆、上下文或协作结果发生改变。下游决策影响取证，含协同结果差异与 AI 交互日志。flag 取证须满足面板提交值与截图/正文值双通道一致，并含访问身份证明。A2A 目标另需结构化成功判据与清理证据。

## 5. 行为约束（What）

执行顺序固定为拓扑发现、消息操纵、智能体冒充、共享记忆投毒、上下文投毒、工作流破坏、下游取证、flag 取证。每一步须先完成证据落盘并通过质量门，才可进入下一步。命令须带真实主机与端口，可被技术读者直接复制执行。生效判定不得以状态码、自身输入回显或协同步骤数变化为准，须有受害者侧实体内容或动作证据。效果等级按四值互斥记录，不得夸大。

## 6. 失败与豁免

目标为单 agent 或无协同端点时，记录判定依据后改走单 agent 或 MCP 工具技能。消息操纵部分生效或模型非确定性拒绝时，如实记录效果等级，不重复重试同一被拦截动作。被消息签名或护栏拦截时记录原因并评估替代路径。注册需认证、Card 无主机名或无可写端点时跳过对应面，不绕过认证、不伪造凭据。清理失败须显式告警并说明残留影响。疑似诱饵机记录依据后在时限内结束，不在零分主机空耗。

## 7. 不在范围

单 agent 间接提示注入的基线手法，由上游技能承担。Agent Card 与 OpenAPI 的枚举命令，由侦察阶段承担。威胁建模与清单编号定义，由威胁建模阶段承担。演练报告排版与提交动作，由报告技能承担。与本技能无关的业务系统提权与横向移动。真实目标之外的凭据获取或持久化。

## 1. 布尔验收条件（AC）

| AC | US | 验收条件（布尔） | 判定方式 |
|---|---|---|---|
| AC-01 | 01 | 给定目标输入面，当枚举执行，则输出含图像/PDF/OCR/浏览器四类通道字段 | 字段断言 |
| AC-02 | 02 | 给定候选 target，当能力探测执行，则 image_path/文件输入支持性被记录 | 替身断言 |
| AC-03 | 03 | 给定载荷类型，当伪装执行，则白底白字/PDF 元数据/OCR 三类中至少一类产出 | 输出断言 |
| AC-04 | 04 | 给定图像 target 与载荷，当发送执行，则请求与响应入记忆 | 记忆记录断言 |
| AC-05 | 05 | 给定文档载荷，当文件上传执行，则隐藏指令随文件摄取且响应被记录 | 替身调用计数 |
| AC-06 | 06 | 给定 Web UI target，当 image_path 注入执行，则消息片含 image_path | 机读结果断言 |
| AC-07 | 07 | 给定载荷与变换类型，当转换器执行，则输出为变换后字符串 | 双输入比对 |
| AC-08 | 08 | 给定响应，当确定性评分命中则判 success 且不追加 LLM judge（C6）；不确定转 LLM 评分 | 分级断言 |
| AC-09 | 08/13 | 给定无法判定响应，当分级执行则标 UNDETERMINED 而非 success | 边界夹具 |
| AC-10 | 09 | 给定单步，当证据产出则命令/输出/截图钩子三字段齐全 | 证据契约测试 |
| AC-11 | 10 | 给定单步，当证据产出则 ai_log 含 prompt/模型/输出/采纳四字段 | 证据契约测试 |
| AC-12 | 11 | 给定全部步骤，当复现走查则每步可按 multimodal-NN 路径 copy/paste 复现 | 路径+parser 断言 |
| AC-13 | 12 | 给定 flag 值，当取证则面板值与截图/正文逐字一致 | 双通道断言 |
| AC-14 | 14 | 给定部分生效响应，当分级则如实记录不高估 | 部分生效夹具 |
| AC-15 | 15 | 给定未装 PyRIT 的 CI，当测试执行则替身可注入且全外部行为通过 | S2 实跑 |
| AC-16 | 16 | 给定规格/门禁全文，当 C8 检查则三/五件套/双通道/11 阶段/to-spec 两遍存在 | 人工抽检 |

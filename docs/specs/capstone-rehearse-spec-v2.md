## 2. Testing Decisions

1. **只测外部行为**：断言输入 → 机读结果/矩阵/时间线/分级/报告/退出码；不断言私有顺序。AC-03 替身计数是唯一例外。
2. **替身边界**：两新接缝注入内存清单与固定时钟；片段解析复用既有 `EvidenceSource` 假后端；不 mock 标准库。
3. **夹具矩阵**：全就绪 / 删四要素 / 证据链断点 / 23·24·25h / 29·31min / 未演练却声称通过 / 缺一件产出。
4. **红—绿—重构**：每 AC 先留红阶段输出，最小改动转绿，重构复跑；三轮留痕。
5. **既有参考测试**：`test_verify_evidence`（机读/退出码）、`test_loot_manage`（索引同源）、`test_report_exam`（片段契约）、`test_*_evidence_contract`（夹具风格）。
6. **不新增 S2 攻击夹具**：演练验收域，S2 覆盖即 AC 集；契约测试断言三件套与 AI 日志（AC-21）。

## 4. 收敛决策（对象图与 seam）

- **对象图**：无 PyRIT 对象。模型 `Stage` / `CoverageRow`（4 字段，AC-01）/ `TimelineSlot`（6 字段，AC-05/08）/ `Gap`（`severity`=blocking|non_blocking, `suggestion`）/ `RehearsalResult`（`schema_version`+上述+`ready_for_exam`+`pending`+`overtime`）；版本化机读结果为下游唯一消费面。
- **seam**：与阶段 2 结论一致、数量未增加——`StageInventory`（仓库扫描/内存清单）与 `Clock`（固定值）置于走查入口最高层；`EvidenceSource` 复用既有协议；否决理由见 v1 §4。
- **依赖方向**：单向 `入口 → 编排 → 两接缝 → 既有判据（只读）`；既有模块不反向依赖。
- **错误行为**：输入非法 → 退出码 2 且无 `passed`；片段路径缺失 → `evidence_chain=false` 入缺口，不抛异常。
- **假后端**：标准库可注入协议，无外部进程/网络/LLM。

# foothold-ad — 行为规格 v1（七节）

> 回溯补录：本规格在实现完成后补齐（实现先于规格），偏差记录见 `foothold-ad-gate-stage2.md`。

## 1. Problem Statement

课程 Ch11 的域级攻击面——Kerberos 票据、ADCS 模板、目录复制权限、域信任滥用、域控收敛——在技能库中没有承载者。既有传统技能止于公网入口、主机提权与内网横向，到达域内后无判据可用。后果是 capstone 的 Domain Admin 目标与 `proof.txt` 无法由技能产出，演练只能登记缺口。

## 2. Solution

新增技能 foothold-ad：以「域内立足点移交」为唯一输入，输出域级升级路径与域控取证。不承担入口利用、主机提权与横向；在无真实域环境中，以离线工件完成判定，并把「无法判定」与「不可信输入」作为一等结论输出。

## 3. User Stories

- US-01 接收移交：确认会话、凭据、可达域控三项前置，缺项即阻断并回退。
- US-02 枚举域与信任：输出根域/子域、信任方向、SID 过滤状态。
- US-03 识别可攻击的 Kerberos 账户：有 SPN 且启用、关闭预认证、非约束委派三类。
- US-04 获取票据：记录加密类型与工单；被拒时记录依据而非重试。
- US-05 判定 ADCS：ESC1 需无签发要求、可控主体、客户端认证 EKU、低权可注册；ESC8 需 HTTP 注册端点且 EPA 未启用。
- US-06 判定目录复制：非域控主体持有完全复制权限即成链，仅部分权限记部分能力。
- US-07 判定域信任：双向可传递与跨域高权主体同时成立才算路径成立。
- US-08 域控收敛：取得 `proof.txt`，面板值与截图值逐字一致。
- US-09 路径沉淀：输出域级路径图与凭据索引，可被报告无损引用。
- US-10 无环境采集：输出「缺什么、用什么命令采、采完要有什么字段」的清单。
- US-11 来源可追溯：每条工件有哈希、采集工具与版本、采集时间、操作者。
- US-12 结论可复现：同一工件集合重复执行得到同一结论摘要。

## 4. Implementation Decisions

- 判据取值复用既有五值，并追加「不可判定」表达证据不足；不新造语义。
- 离线优先：工件是唯一事实源；无工件不出结论，字段缺失不按默认值推断。
- 凭据只保留指纹（算法 + 前 8 位 + 长度 + 位置），明文不落任何输出。
- 输入质量三级处置：缺失或损坏即阻断；版本不受支持即不可判定；字段缺失即不可判定并写明缺项。
- 不改既有技能判据、不改证据片段结构、不改共享工具契约。
- 未知枚举值（信任方向、委派形态、签发要求、EPA 状态）一律不可判定，不得默认成安全或危险。

## 5. Testing Decisions

- 判据以纯函数实现，夹具驱动，零网络零第三方。
- 每条新判据必须配一条「应判不可判定而非猜测」的反例。
- 负向输入（空文件、截断、非 UTF-8、超深嵌套、超限体积、类型错乱）必须各有一例。
- 确定性以摘要哈希断言：同输入同值，键序变化不影响结果。
- 业务代码行覆盖率不低于 90%。

## 6. Out of Scope

- 公网入口利用、本地提权、主机横向（属传统技能）。
- 真实域环境联调（无靶场；以夹具验证代替，表述不得写成环境实测）。
- 影子端点发现（属侦察技能）。
- 主线 11 阶段流程本身（由流程规范定义，本规格只描述技能行为）。

## 7. Further Notes

- 与演练技能的约定：本技能当前为可执行增量，演练走查只能记部分覆盖，不得记已就绪。
- 与战利品、证据校验技能的衔接：票据、凭据指纹、域控 flag 取得后即时登记；证据结构须能被报告直接复用。
- 已知偏差：规格晚于实现产出；阶段 1 仅完成课程文档一手源，外部权威源（ATT&CK、ADCS 研究）已核实但未覆盖商业工具文档。

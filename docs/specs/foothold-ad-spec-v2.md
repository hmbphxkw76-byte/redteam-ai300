## 工程规格定稿 (v2)

# foothold-ad — 工程规格 v2（定稿 · 可验证性收敛）

> 回溯补录：v2 与 v1 同日补齐，两遍独立留痕但均晚于实现；偏差见 `foothold-ad-gate-stage3.md`。

## 1. 布尔验收条件（AC）

| 编号 | 条件（可真/可假） | 复验方式 |
|---|---|---|
| AC-01 | 无工件时依赖步骤为 `BLOCKED`，`missing` 列出缺失文件名 | 夹具空目录执行，断言 `blocked_steps` |
| AC-02 | 工件损坏（空/截断/非 UTF-8）时 `parse_errors` 有记录且步骤 `BLOCKED` | 三类负向夹具 |
| AC-03 | `schema_version` 主版本不受支持时步骤 `UNDETERMINED`，注记含版本号 | `2.0` 夹具 |
| AC-04 | 未知信任方向、未知委派、缺签发要求、缺 EPA 状态均为 `UNDETERMINED` | 四类未知枚举夹具 |
| AC-05 | ESC1 仅在「无审批 + 无授权签名 + 可控主体 + 客户端认证 EKU + 低权注册」同时成立时命中 | 正例 + 4 个缺项反例 |
| AC-06 | ESC8 仅在「HTTP 注册端点 + EPA 未启用」时命中；EPA 启用不命中 | 三态夹具 |
| AC-07 | 目录复制仅 `Get-Changes-All` 判成链，仅 `Get-Changes` 判部分能力 | 两条 ACE 夹具 |
| AC-08 | 域信任路径需「双向可传递 + 跨域高权主体」同时成立 | 正例 + 单条件反例 |
| AC-09 | 域控 proof 双通道不一致时该步 `BLOCKED` | 不一致夹具 |
| AC-10 | 明文口令与完整哈希不出现在结论 JSON 与证据参数中 | 含明文夹具 + 断言 |
| AC-11 | 同一工件集合两次执行 `digest` 相同；JSON 键序反转后不变 | 确定性夹具 |
| AC-12 | `cli verify` 对完整清单退出 0、对篡改工件退出 1 | 端到端调用 |
| AC-13 | `cli preflight` 输出含缺失项、采集命令、期望字段、依赖步骤 | 空目录与半成品目录各一例 |
| AC-14 | 循环 ACE 图与同形字账户名不导致死循环或错误合并 | 对抗夹具 |
| AC-15 | 业务代码行覆盖率 ≥90% | `measure_coverage.py --min 90` |

## 2. Testing Decisions

- 测试分层：解析层（工件容错）、判据层（纯函数）、编排层（三级处置）、接口层（CLI 退出码）、不落盘层（凭据）。
- 每条 AC 至少一个断言；AC-05/AC-06 用「正例 + 缺项反例」成对覆盖，防止判据退化为「字段存在即命中」。
- 负向输入与对抗输入单独成文件，避免与正例混读。
- 确定性不以「重复跑看着一样」判定，而以摘要哈希断言。

| 门禁 | 命令 | 与 AC 的关系 |
|---|---|---|

| 主线留痕 | `validate_skill_mainline.py --strict` | 规格 v1/v2 与 10 份门禁记录存在 |

## 4. 收敛决策（对象图与 seam）

- **唯一 seam**：工件目录（文件系统）。所有判据以此为输入，网络与 AD 工具不进入依赖链。
- **不引入 CommandRunner**：本技能不执行命令，仅组装证据参数；命令执行由操作员在证据环节完成。若后续需要实跑，再以注入式 runner 引入，避免提前抽象。
- **对象图收敛**：目录、模板、信任三类工件 + 票据/proof 两个可选工件，共五个文件；不引入数据库或索引。
- **判据与证据分离**：判据产出结论与依据；证据参数组装只读结论，不反向影响判据。

## 5. v1 → v2 差异清单（逐条可追溯）

| 差异 | v1 表述 | v2 收敛 | 理由 |
|---|---|---|---|
| 验收形态 | 用户故事 | 15 条布尔 AC | 可机器判定 |
| ESC1/ESC8 | 「分别判定」 | 明确条件组合与缺项处置 | 对齐 CERTIFIED PRE-OWNED 定义 |
| 输入质量 | 未分级 | 三级处置写入 AC-01..AC-03 | 缺件、损坏、版本不支持语义不同 |
| 来源完整性 | 未覆盖 | AC-12 + AC-13 | 无真实环境时工件即事实源 |
| 确定性 | 「同输入同输出」 | AC-11 以 digest 断言 | 可自动校验 |
| 覆盖率 | ≥90% | AC-15 绑定命令 | 门禁可复现 |

## 6. 风险与核实闸

| 风险 | 影响 | 闸门 |
|---|---|---|
| 无真实域环境，判据未联调 | 规则可能在真实环境漏判/误判 | 表述限定「夹具验证」；实跑前须在具备域环境时复核 |
| 工件由第三方工具产出，字段命名可能漂移 | 解析静默失败 | 字段缺失即 `UNDETERMINED`；`verify` 强制清单登记 |
| ESC 判据随研究演进（ESC9+ 未覆盖） | 覆盖不全 | 本规格只声明 ESC1/ESC8；扩展须新 AC |
| 规格晚于实现 | 可能「按实现写规格」的循环论证 | 差异清单与门禁记录如实标注，不回溯改写结论 |
| 主线阶段 4/5（工单与分类）未执行 | 追溯链缺 issue | 记录为偏差，不伪造 issue |

# foothold-traditional — 行为规格 v1

> 回溯整理：依据 `skills/foothold-traditional/SKILL.md` 与既有实现、测试归纳；**不代表原流程按序执行**。
> 整理日期：2026-11-27　状态：定稿（v1）

## 1. 背景与目标

演练流水线在 `recon-ai` 之后需要「立足点」环节：取得传统攻击链的公网入口、内网横向与本地提权。缺少该承载者时，2 台传统向量机（10 分/台）无人认领，AI 向量技能声明的「已取得可达 AI向量机的内网立足点」前置无法满足，报告的 Attack Walkthrough 也缺少传统链路证据。

目标是单技能内完成 2 条攻击链 × 3 台链式主机的传统路径，认领其中 2 台传统向量机并取得 `trad_vector.txt`；同时为 4 台 AI向量机与独立机供给内网可达性（立足点移交）。技能边界止于「移交」，AI 特定利用与域控收敛不在其内。

## 2. 使用者与触发场景

- 红队演练者（agent 承接）：需要一条可复现、可评分的入口到横向链路。
- 报告撰写者：需要与 Attack Walkthrough 直接兼容的证据片段。
- 战利品管理者：需要凭据、会话、flag 的即时登记。
- 编排层：需要「链式入口」语义——任一链的初始立足点是后续 AI 向量利用的前置。

触发条件：`recon-ai` 传统面枚举完成，`threat-model` 已给出优先攻击路径，需要取得公网入口立足点、内网横向与本地提权。

不触发：只需 AI 向量利用（移交 attack-ai-*）；只需域控收敛（编排层按需触发）。

## 3. 输入

- `recon-ai` 资产清单：外部入口、服务版本、初始访问向量。
- 已获取凭据（可选），来源为战利品登记簿中的既有条目。
- `threat-model` 的优先攻击路径；疑似诱饵机的 `decoy-detect` 判定结论。
- Ch9 扩展输入：调用方采集的 SSRF 响应文本、目标机 `sudo -l` 输出。本技能不生成 SSRF 载荷。

## 4. 输出与产物

- 主链八步 `trad-01`..`trad-08`，每步「确切命令 + 关键输出 + 截图钩子」，统一经 `tools/collect_evidence.py --strict` 落盘。
- 提权前后权限证明（`id`/`whoami` 对照同屏）。
- 2 台传统向量机 `trad_vector.txt` 的双通道一致（面板提交值 == 报告截图/正文）。
- 横向路径图（入口 → 各主机 → 汇聚方向）与立足点移交清单（会话/凭据、可达 AI向量机路由、战利品索引）。
- Ch9 两步 `trad-09`/`trad-10` 的类型化五值结论与 strict 证据；凭据只产指纹（键名 + 长度 + 位置）。
- 每个取得的凭据/会话/flag 即时登记至 `loot-manage`。

## 5. 行为约束

- 顺序推进：入口利用 → 首台提权取证 → 内网横向 → 次台提权取证 → 路径沉淀与移交；未过质量门不得进入下一步。
- 每条攻击链自单一公网入口起始；横向优先复用已登记凭据/会话，不重新爆破。
- 不夸大权限状态：提权失败时以当前权限继续并记录限制。
- 第三方 exploit 必须附来源链接或代码副本及修改说明；示意命令标来源，不伪造回显。
- 凭据明文不落 output 与证据，只保留指纹。
- 术语以 `GLOSSARY.md` 为准（攻击链、传统向量、诱饵机、时间盒、战利品登记簿、攻击路径等），禁用废弃术语。
- 不越界：AI 特定利用移交 attack-ai-*；域控收敛与域级攻击不在本技能。

## 6. 失败与豁免

- 公网入口不可利用（版本无对应 exploit、被拦截）：记录判定依据后换入口或换链，不长时间盲试；两条链均不可达时上报编排层重估威胁模型路径。
- 本地提权失败：如实以当前权限继续横向并记录缺口，汇总至 `capstone-rehearse` 缺口清单。
- 次台主机实为 AI向量机：记录判定依据后移交对应 AI 向量技能，不越界实施 AI 特定利用。
- 目标为疑似诱饵机：≤30 分钟时间盒内判定并主动放弃，记录理由，不在 0 分主机空耗。
- 证据落盘失败：判定未过门禁，不得以对话内容替代证据。

## 7. 不在范围

- AI 特定利用（agent / RAG / MCP / embedding / 供应链）。
- 域控收敛与域信任、票据、ADCS 等域级攻击。
- 截图捕获实现（仅接收路径或钩子）。
- SSRF 载荷生成与 CVE-2025-23266 提权本体（分别由 recon 侧与 attack-infra ch9-gpu 承担）。
- 主线 11 阶段流程本身（由流程规范定义）。

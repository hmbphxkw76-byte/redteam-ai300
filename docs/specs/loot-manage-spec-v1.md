# loot-manage — 行为规格 v1（历史留痕回填）

> 回溯整理：依据 `skills/loot-manage/SKILL.md` 与既有实现、测试归纳；**不代表原流程按序执行**。
> 整理日期：2026-11-27　状态：定稿（v1）

## 1. 背景与目标

红队全程产出的战利品（凭据、会话、flag、攻击路径、定格式问答）若散落于各攻击技能输出与对话上下文，会同时造成三类损失：证据散失导致事后补录遗漏；无法查表复用导致对已控目标重复爆破；报告回溯断裂导致证据链无法无损还原。本技能提供贯穿作战全程的单一事实源登记簿，把每条战利品即时沉淀为可机读、可追溯、可复用的结构化记录。对齐能力域 D1（红队生命周期资产管理）与 D10（威胁建模的攻击路径沉淀），计分单元为通用，属 P0 运维型技能，价值在「不漏证、不乱证」。

目标：任意一条登记行都能经证据片段路径还原完整「命令 + 输出 + 截图」，并支撑提交前的双通道核对与横向移动前的复用决策。

## 2. 使用者与触发场景

使用者为执行授权评估的红队分析人员，在作战窗口内持续登记，而非阶段末集中补录。触发条件为任一攻击技能取得新的凭据、会话、flag，或完成一段攻击路径，需要即时沉淀。典型场景：取得口令或 token、建立持久会话、拿到计分 flag、完成入口到横向的一段路径、课件定格式问答取到答案。

不适用于：尚无任何战利品且未记录空态的场景，此时应先记录空态与原因；截图捕获本身不属于本技能触发范围。

## 3. 输入

- 各攻击技能产出的战利品本体：凭据、会话接入方式、flag、攻击路径摘要。
- 战利品取得步骤经共享证据工具产出的片段路径；本技能只引用，不重复取证。
- 侦察产出的资产清单，用于核对来源主机与路径节点。
- 时间戳（ISO8601）与状态（有效/失效、存活/失效、已取证）。
- flag 的双通道信息：控制面板提交值与访问证明截图路径。
- 定格式问答的题面、答案、格式标识与证据片段路径。

## 4. 输出与产物

- 战利品登记簿 `loot/registry.md`：固定八列（编号/类型/内容/来源主机/证据片段路径/时间戳/状态/双通道）。
- 「攻击路径」小节：入口 → 主机 → 横向的路径摘要，供报告 High-Level Attack Path 复用。
- 「问答取证」小节：题面、答案、格式、证据片段路径四段式。
- flag 行的双通道占位：面板提交值 + 截图路径。
- 机读校验结果：八项检查结论、flag 清单与空态原因。
- 空态记录：全程无战利品时记录原因，作为综合演练缺口清单输入。
- 凭据串链视图：复用攻击路径字段，标注密钥类型与指纹（可选、缺省不阻断）。

## 5. 行为约束（What）

- 登记必须即时：取得即追加一行，不得留到阶段末补录。
- 登记簿是单一事实源：战利品不得散落于对话上下文，对话中一律以编号 `L-<n>` 指代。
- 登记簿只存证据片段路径指针，不重复存储证据本体。
- 表结构固定八列；列序可调整，但列名集合必须完整。
- 类型限定为凭据、会话、flag；状态必须与类型匹配。
- 编号 `L-<n>` 全局唯一且格式合法。
- 来源主机不得为空或占位符，否则视为不可追溯。
- 每行证据片段路径必须真实存在；flag 行必须同时提供面板值与截图路径。
- 有登记行时「攻击路径」小节必须非空。
- 失效的凭据或会话必须原位更新状态并保留原行，不得删除。
- 域控 flag 登记须标注「仅可提交一次」。
- 定格式问答必须可按格式机读校验，覆盖 OS build 与 LLM 地址两类。
- 技能不得联网、不得外发战利品内容、不得引入攻击框架或 PyRIT。
- 术语必须符合 `GLOSSARY.md`，禁用废弃术语。

## 6. 失败与豁免

- 凭据或会话失效（目标修补、口令轮换）时，如实将状态改为「失效」并保留原行。
- 全程无战利品（目标不可达）时记录空态与原因；空态本身即有效产出，作为缺口信号时另行标注。
- 登记簿不含截图本体，截图捕获实现不在本技能范围。
- 证据片段被移动导致引用缺失时，补齐路径后重新过质量门；不得以对话记忆替代证据。
- 云凭据只登记脱敏指纹；明文（含引号包裹）一律拒绝登记。
- 问答指纹等可选字段缺省时不阻断登记。

## 7. 不在范围

- 不执行任何攻击动作，不产出攻击逻辑。
- 不重复取证，不实现截图捕获。
- 不把战利品外发到托管服务或第三方接口。
- 不引入 PyRIT 或任意攻击框架。
- 不重新定义共享证据契约，不改变 verify-evidence 与 report-exam 的判据语义。
- 不在规格与文档中写入真实凭据明文或 flag 明文。

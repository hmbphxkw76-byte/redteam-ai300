# osai-handoff-gateway 工程规格 v2（可验证性收敛）

> 输入：本文 v1 + `docs/research/osai-skill-handoff-design.md`（阶段 1）。
> v1→v2 差异：把八条 User Story 改写为布尔验收条件，每条附命令或判据。

## 1. 验收条件（布尔，逐条可判定）

| ID | 验收条件 | 判据 / 命令 |
|---|---|---|
| AC-1 | 资产清单可解析且 `ASSET_FIELDS` 七字段齐全 | `H1` 校验返回 PASS 且无缺字段理由 |
| AC-2 | 资产存在性三态（存在/不存在/不可判定）不被折叠为二态 | 夹具含 UNDETERMINED 时 H1 保留该状态 |
| AC-3 | 计分步骤的截图钩子不计为真实截图 | `--shot-cmd` 夹具下 H2 返回 BLOCKED |
| AC-4 | flag 登记行的面板值与截图路径分离 | `derive_panel_flags()` 只取 `面板=` 列，不取 `截图=` |
| AC-5 | 失效战利品不被复用 | 状态为「失效」的行在 H4 返回 BLOCKED |
| AC-6 | 侦察片段按 host 进入报告枚举段 | H5 校验确认 recon 片段未被 `real_only` 过滤 |
| AC-7 | 提交前断图检查、时间锚、加密检查均有判定 | H6 三项各自有布尔结果与理由 |
| AC-8 | 六段判定只取 PASS / BLOCKED | `GateResult` 值域断言 |
| AC-9 | 每条设计核心条款有实现锚点 | 对齐矩阵脚本输出零缺失 |
| AC-10 | 既有 skill / tool 实现零改动 | `git diff --name-only` 不含既有工具目录 |
| AC-11 | 零第三方依赖、零 PyRIT 运行时依赖 | import 白名单断言 |
| AC-12 | 覆盖率 ≥80% | `measure_coverage --target osai-orchestrator --min 80` |

## 2. 测试决策

- 每 AC 至少一条 unittest 用例；失败用例先于实现产出「红」。
- 对齐矩阵用设计文档条款 ID（A1–A8）映射到代码锚点，脚本可机读。
- 全量测试含既有 16 技能回归，确保无破坏。

## 3. 门禁映射

| AC | G0 基线 |
|---|---|
| AC-1/2/6 | B2 术语与决策一致 |
| AC-3/4/5/7/8 | B4 证据契约、B5 证据与 flag |
| AC-9/10 | B8 可追溯性、零破坏约束 |
| AC-11/12 | B3 语法构建、B6 CI 门禁 |

## 4. 风险与核实闸

- H5/H6 若需触碰既有消费者语义，按 GOVERNANCE §8.3 显式声明；本次仅旁路校验，不触碰。
- panel_flags 派生若遇到非标准登记行，返回 BLOCKED 并给出原始行，不猜测。
- 时间锚缺失时 H6 返回 BLOCKED，不用系统当前时间代替。

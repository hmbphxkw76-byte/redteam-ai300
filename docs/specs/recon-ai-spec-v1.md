# recon-ai — 行为规格 v1（历史留痕回填）

> 回溯整理：依据 `skills/recon-ai/SKILL.md` 与既有实现、测试归纳；**不代表原流程按序执行**。
> 整理日期：2026-11-27　状态：定稿（v1）

## 1. 背景与目标

AI 资产侦察是红队前置环节：在发起攻击前定位目标环境的 AI 组件与暴露面，避免空耗与误判。
本技能把 AI 资产枚举固化为 7 类可复现步骤，产出结构化资产清单与可复用证据，供下游按资产 ID 引用。
目标是「先看清再开打」：覆盖 LLM 引擎、模型服务、RAG 库、向量库、agent 系统、MCP·工具面、护栏七类。
分类对齐 D2 能力域，计分单元为「通用」；技能优先级 P0，是 `attack-*` 系列的前置输入。
本规格只描述行为与产物，不规定实现技术选型。

## 2. 使用者与触发场景

使用者为已获授权的红队分析人员，在考试或演练窗口内执行侦察。
触发条件：对目标环境发起红队行动前，需定位 AI 资产与攻击面。
典型场景：仅有入口 URL 或网段；已有部分主机与凭据；需要判断目标是否为诱饵机。
执行分级由使用者选择：默认被动；仅在明确授权时启用主动档定向端口。
未获授权时只允许被动分级，且不得进行任何状态变更。

## 3. 输入

- 目标入口或网段，形如 URL、主机或 CIDR。
- 可选已知主机、端口、凭据线索与实验室标识。
- 执行分级：`passive`（默认）或 `active`（显式）。
- 输出目录、运行标识与时间盒参数。
- 证据工具契约：`tools/collect_evidence.py` 的命令、输出、截图与清单参数。
- AI 交互日志通道与 flag 双通道值（面板值、截图值）。
- 可选外部观测：前端产物、响应头、部署配置、SSE、OpenAPI 与 Agent Card。

## 4. 输出与产物

- 7 个证据片段 `recon-01..recon-07`，各含确切命令、关键输出、截图、脚本说明、AI 日志与 flag 双通道。
- 每步访问证明截图；无浏览器时标注「截图待补录」并使门禁失败。
- 结构化资产清单（markdown + JSON），7 字段：资产ID、组件类别、产品引擎、版本、暴露端点、凭证指纹、关联 step_id。
- 缺口台账：类别、步骤、端点、依据、下一步；`UNDETERMINED` 不入资产表。
- `MANIFEST.jsonl` 证据清单与 `run.json` 运行元数据。
- 自校验报告与 `verification.json`（C1–C9），结论由实测派生。
- 可选 Ch2 旁路分析产物（离线行为画像），不改 C1–C9。

## 5. 行为约束（What）

- 先被动后主动：响应头、部署配置、前端产物、SSE 优先；主动档仅定向端口，≤8 个，禁全扫描。
- 逐类枚举 7 类组件，每类独立 step_id；A2A、契约提取、影子端点沿用 recon-05，不新增 step_id。
- 存在性三值：存在 / 不存在 / 不可判定；200 不等于存在，回退页记不存在，超时记不可判定。
- 仅 `PRESENT` 建资产；不可判定入缺口台账；不得以产品文档替代运行时事实。
- 请求总量 ≤12 且只读；不调用重置端点、不上传、不变更目标状态。
- 凭据只记指纹（`Bearer-<前8位哈希>`），不落盘明文。
- 每步经共享证据工具严格模式产出三件套；缺任一件即门禁失败。
- 单面失败不阻塞其余枚举，但对应门禁失败并记入 `failed_steps`。
- 疑似诱饵时记录依据、降级轻量枚举，30 分钟内结束。
- 术语符合 `GLOSSARY.md`；资产清单可被下游按资产 ID 复用，无需二次枚举。

## 6. 失败与豁免

- 诱饵机：0 分、无 AI 组件 → 记依据后降级，≤30 分钟结束。
- 组件无法指纹识别 → 记「无法识别」及原因，不阻塞其余枚举。
- A2A Card 不可达或非协议 JSON → 记 `ABSENT` 并留原始响应。
- SIEM 不可读 → 记 `UNDETERMINED`。
- 探测暴露 → 立即中止该面，记录暴露点与时间窗，转被动观测，不重试同一动作。
- 无浏览器 → 截图标「截图待补录」，C4 失败、退出码 1，不得占位图充数。
- garak 未接入首扫属已知偏离（V4），在设计中登记。

## 7. 不在范围

- 不执行攻击：不构造越狱/注入利用、不投毒、不做模型抽取、不提权外联。
- 不做爆破：无口令猜测、无 token 枚举、无大字典并发目录扫描。
- 不做全端口扫描；主动档仅定向端口。
- 不写目标：不调用重置端点、不上传内容、不变更状态。
- 不生成提交物：PDF、`.7z` 与提交属 `report-exam` / `verify-evidence`。
- 不深挖诱饵；不推断未观测事实；不伪造截图。
- 不新增 step_id，不改七字段契约；Ch9/Ch2 不改变主链判定语义。
